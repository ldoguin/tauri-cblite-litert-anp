Identity

A Name Each Company Owns

did:wba

A DID on the company’s own domain, resolved over HTTPS. No registry and no platform to join: keys are found where the company publishes them.

Ed25519 signatures

Every document and message is signed by the node that wrote it, so a reader can verify any copy, wherever it was stored.

Signed HTTP requests

Each request carries an HTTP Message Signature from the caller’s DID key: a company knows who is asking without a shared secret.

Cost. Every company must run a domain and publish a DID document. In the tests a private certificate authority stands in for the web’s.

ANP identity is did:wba: the DID is resolved from the company’s own HTTPS origin. Every node holds an Ed25519 key; documents are signed by the node that wrote them, and each HTTP request is signed with HTTP Message Signatures (ANP-02). The tests run every DID over HTTPS behind TLS fronts with a certificate authority made for the run.
