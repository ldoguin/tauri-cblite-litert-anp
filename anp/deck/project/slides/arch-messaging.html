Messaging

Private Between Strangers

Finding

Signed descriptions

Each company signs an agent description. A search agent lists only the ones it verified against the company’s DID.

Asking

Encrypted direct messages

Requests, quotes and acceptances travel end to end encrypted, so no relay or proxy can read them.

Coordinating

An MLS group

The plan is posted to a group on a separate host, which relays ciphertext it cannot read.

Why ANP across companies. Inside one company the agent’s tasks use A2A. ANP is what crosses domains: identity, discovery and private messages with no shared platform. Cost: key packages and group state to keep, and a group host to run.

ANP-07 and ANP-08 give signed agent descriptions and a search agent that indexes only descriptions it has verified. ANP-09 P5 gives end-to-end encrypted direct messages with agents on other stacks; P6 gives MLS groups, where the group host orders and relays but holds no key. Inside one company the agent’s own tasks speak A2A.
