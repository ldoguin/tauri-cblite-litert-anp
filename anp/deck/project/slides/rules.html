The model proposes. The rules decide.

Each decision in the agent’s log names the rule that made it. Rules: arrive before the first loss, cheapest wins, re-plan when a warehouse has too little room, move only what is worth it, give away what cannot be kept cold, replace what cannot be saved. An on-device model can propose the carrier and the storage, but a proposal is followed only if it passes every rule.
