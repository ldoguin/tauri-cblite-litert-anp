The brain

Rules Decide, A Model May Propose

Rules

Food-safety limits, carrier timing, budget limits. Deterministic, so every decision in the log names the rule behind it.

An on-device model

LiteRT-LM runs a small chat model locally. It proposes a carrier and storage; a proposal is followed only if it passes every rule.

One Rust binary

anp-node, on axum and tokio: the same program is a store, a company, a head office or a phone, by its flags.

What the test showed. Qwen2.5-1.5B answered in 48 seconds and its proposal passed every rule, but its stated reason was wrong about which warehouse was cheaper: the rules are trusted, not the explanation. Cost: no LiteRT-LM runtime for Windows, so it ran in WSL.

The model proposes and the rules decide: a proposal is parsed, then vetted against the same rules as the agent’s own plan, and set aside with the rule it broke if it fails. The model run was Qwen2.5-1.5B-Instruct on two CPU cores in WSL; the node is a Rust workspace with axum and tokio, and the end-to-end checks are Rust tasks that start real nodes.
