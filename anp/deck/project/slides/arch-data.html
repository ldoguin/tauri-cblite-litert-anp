Couchbase Lite In Every Node

An embedded database

The store, each company and the head office each keep a Couchbase Lite database, with eight collections in one scope: inbox, tasks, agents, revocations, telemetry, rescue, approvals and tokens.

Offline first

A store keeps writing with its link cut and replicates when it returns. The head office catches up on its own.

One writer, signed

Each document is written by one node and signed by it, so replication produces no conflict and any copy can be verified.

Why a database and not files or a queue. The record has to survive a dead link and still be provable later. Cost: a signature and rollback check on every read.

Collections live in scope a2a. A node writes only documents named for itself and signs them; peers verify the signature, the author’s right to write that kind of document, and a sequence number that only goes forward, so an old copy cannot replace a newer one. Because each document has a single writer there is nothing to merge. Replication runs peer to peer or through Sync Gateway.
