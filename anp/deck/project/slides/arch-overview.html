The whole system

Six Layers, Each With One Job

6 · The brain

Rules decide. An on-device model may propose.

5 · Agent protocol

A2A tasks inside a company; ANP discovery and quotes between companies.

4 · Commitments

A signed quote chain, and a Biscuit token that caps what the agent may sign.

3 · Messaging

Signed HTTP requests, encrypted direct messages, MLS groups.

2 · Identity

A did:wba on each company’s own domain, with Ed25519 keys.

1 · Data

Couchbase Lite in every node; Sync Gateway and Server in the retailer.

The system in six layers. Data at the bottom is the Couchbase part: every node has a Couchbase Lite database, and inside the retailer Sync Gateway and Couchbase Server carry the stores’ records. Identity is a DID on each company’s own domain. Messaging is signed HTTP, end-to-end encrypted direct messages and MLS groups. Commitments are a signed quote chain and a Biscuit spending token. The agent protocol is A2A inside a company and ANP across companies. The brain is a rules layer with an optional on-device model.
