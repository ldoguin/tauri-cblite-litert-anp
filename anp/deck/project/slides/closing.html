What made it possible

The Agent Reasoned Freely, But Could Only Sign What Its Token Allowed

  • Found and verified strangers. DIDs on each company’s own domain, signed messages, no shared platform.
  • Spent within limits the other side enforced. A Biscuit token bound to the store’s DID.
  • Kept a record no one can rewrite. Six deals, each four signed messages that audit offline.
  • Seen from head office. Couchbase Lite, Sync Gateway and Couchbase Server carry every store’s records.

cargo xtask cold-rescue --gateway
