Decisions from far away

Approvals And Tokens Travel As Documents

The approval

The duty manager’s phone signs a document into the store’s channel. The store acts on it only from a named duty manager: a head office’s signed approval is logged and ignored.

Revocation and new tokens

The authority revokes a lost token. The store stops signing with it, and takes a new one only from a carrier it was told to use, only if it is the authority’s, for this store.

A company outside the retailer would still accept a revoked token: companies do not read the retailer’s gateway.

The approval is a signed document named for the store, the run and the signer, so one node’s approval can never replace another’s; the Sync Gateway sync function lets a phone write an approval only into a store channel it was given. For revocations, the head office verifies the authority’s signature and publishes the revocation; the store reads it through the gateway. A revoked token carried again is refused. The limit: companies are outside the retailer and do not read its gateway, so telling them would be an ANP message from the authority.
