The plan is posted for everyone involved, and the group host cannot read it.

Request, quote, acceptance, confirmation: four signed messages per deal, each naming the previous one by digest. Each company checks the acceptance on its own: the token’s issuer, the DID and key that signed it, the amount, the category, the store. Anyone holding the DID documents and the authority’s key can verify a deal offline, after the token has expired. The group is an MLS group on a separate host, which relays ciphertext it cannot read.
